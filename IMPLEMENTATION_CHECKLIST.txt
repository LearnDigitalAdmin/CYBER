================================================================================
                         ROLLBACK PROCEDURE
================================================================================

If something goes wrong:

1. IMMEDIATE:
   [ ] Disable webhook endpoint temporarily (return 200 OK)
   [ ] Notify users of payment processing delays
   [ ] Gather error logs

2. INVESTIGATION:
   [ ] Check webhook logs for errors
   [ ] Check Firestore for partial records
   [ ] Verify signature validation
   [ ] Check PAYSTACK_SECRET_KEY

3. FIX OPTIONS:
   [ ] If code issue: revert last deploy
   [ ] If configuration issue: fix environment variables
   [ ] If data issue: manually reconcile Firestore

4. RESUME:
   [ ] Re-enable webhook
   [ ] Process any queued payments
   [ ] Notify users issue resolved
   [ ] Document what went wrong

5. PREVENT:
   [ ] Add monitoring/alerts
   [ ] Add manual verification step
   [ ] Implement circuit breaker pattern
   [ ] Add retry logic for failed webhooks
