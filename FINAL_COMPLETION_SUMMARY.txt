================================================================================
                         SYSTEM ARCHITECTURE
================================================================================

PAYMENT FLOW (T0 to FINAL):
1. User selects report (50 KES weekly or 200 KES monthly)
2. Confirms phone number
3. System sends STK push to customer
4. System activates listener (watches Firestore for payment update)
5. User sees: "Report Generation in Progress"
   - Can press 0 (back), 00 (restart), 000 (exit)
   - Listener continues watching in background
6. Customer completes payment on their phone
7. Paystack webhook updates Firestore: status = 'success'
8. Listener detects change in < 1 second via onSnapshot()
9. Listener callback executes:
   - Generates report from shop transaction data
   - Sends report link via WhatsApp
   - Returns user to MY_SHOP_MENU (same session)
   - Cleans up listener
10. User back in shop menu, can continue operations

TOTAL TIME: 3-6 seconds end-to-end

BENEFITS:
✅ Real-time (< 1 second detection)
✅ Automatic (no manual steps)
✅ Seamless (user back in menu automatically)
✅ Efficient (listener-based, not polling)
✅ Reliable (comprehensive error handling)
