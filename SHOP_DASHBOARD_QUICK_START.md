# Shop Dashboard - Quick Start Guide

## Accessing the Dashboard

1. Log into your Cogvana Cyber account
2. Click the **"Shops"** tab (between "Plot Yangu" and "Cyber Services")
3. You're in the Shop Management Dashboard!

---

## Finding a Shop

### Method 1: By Shop ID
1. Enter the shop's unique ID in the search box
2. Click "Search Shop"
3. Shop details appear

### Method 2: By Owner's National ID
1. Enter the shop owner's national ID
2. Click "Search Shop"
3. Shop details appear

---

## Downloading Forms

Once a shop is selected, you can download PDF forms at the top:

- **Sales Form** - For recording daily sales
- **Expense Form** - For recording daily expenses
- **Stock Form** - For recording stock levels

### How to Use Downloaded Forms
1. Download and print the form
2. Give to shop owner to fill manually
3. Collect completed form
4. Enter data into dashboard

---

## Recording Stock

### Add Stock Item
1. Click "Add Stock" button
2. Enter:
   - **Product Name** - e.g., "Rice 50kg"
   - **Quantity** - How much is in stock
   - **Unit** - Pieces, KG, Liters, Boxes, etc.
   - **Date** - Can be today or past date
3. Click "Add Stock"
4. New item appears in stock table

### View Stock
- Stock table shows all current items
- Last updated dates displayed
- Organized by product name

---

## Recording Sales

### Add Sale
1. Click "Record Sale" button
2. Enter:
   - **Product Name** - What was sold
   - **Quantity** - How much
   - **Unit** - Same unit as sold
   - **Price per Unit** - KES amount
   - **Date** - Today or past date
3. System automatically calculates **Total**
4. Click "Record Sale"
5. Sale appears in history

### View Sales
1. Sales table shows all recorded sales
2. Use date filter to narrow results
3. See totals at the top
4. Click trash icon to delete sale

### Date Range Filter
- Set "From Date" and "To Date"
- Click "Filter" button
- Table updates with matching sales

---

## Recording Expenses

### Add Expense
1. Click "Record Expense" button
2. Select **Category**:
   - Rent
   - Utilities
   - Supplies
   - Staff Wages
   - Maintenance
   - Transportation
   - Insurance
   - Marketing
   - Other
3. Enter:
   - **Amount** - In KES
   - **Date** - Today or past date
4. Click "Record Expense"
5. Expense appears in history

### View Expenses
1. Expenses table shows all records
2. Use date filter to narrow results
3. See totals at the top
4. Click trash icon to delete expense

---

## Viewing Reports

### Daily Report
1. Click "Reports" tab
2. Make sure "Daily Report" is selected
3. Pick a date using the date picker
4. View summary cards:
   - **Total Sales** (Blue)
   - **Total Expenses** (Orange)
   - **Profit** (Green if positive, Red if negative)
   - **Transactions** (Purple)
5. Click "Download" to get CSV file

### Range Report
1. Click "Reports" tab
2. Click "Range Report"
3. Set date range (From - To)
4. Click "Load"
5. View summary cards
6. See daily breakdown table below
7. Click "Download" to get CSV file

---

## Tips & Tricks

### Accurate Data Entry
- Always enter the correct date
- Use consistent product names
- Double-check amounts before saving
- Use the notes section on PDF forms for clarifications

### Date Support
- All forms support past dates
- Good for catching up on entries
- Useful for migrating old data
- Date appears in reports

### Filtering & Searching
- Use date ranges to focus on specific periods
- Filter helps find specific transactions
- Reports group by date automatically

### Editing Data
- Currently: Delete and re-enter to correct
- Use notes in PDF forms to explain discrepancies

## Common Scenarios

### Scenario 1: New Shop Setup
1. Search for shop by ID
2. Download all 3 forms
3. Give to shop owner
4. Start recording their operations

### Scenario 2: Catch-Up Data Entry
1. Search for shop
2. Get old sales receipts from shop owner
3. Enter dates matching the receipts
4. Data automatically organizes by date

### Scenario 3: Daily Operations
1. Each morning: Search shop
2. Throughout day: Record sales & expenses
3. Each evening: Generate report
4. Monthly: Review trends in range reports

### Scenario 4: Month-End Reporting
1. Go to Reports tab
2. Select Range Report
3. Set dates: 1st to 30th of month
4. Download CSV
5. Share with shop owner or admin

## Troubleshooting

### Shop Not Found
- ✓ Check shop ID spelling
- ✓ Check national ID (correct format: numbers only)
- ✓ Ensure shop exists in system
- ✓ Contact admin if still not found

### Form Won't Download
- ✓ Check internet connection
- ✓ Try different browser
- ✓ Clear browser cache
- ✓ Try again after few seconds

### Data Not Appearing
- ✓ Refresh page (F5)
- ✓ Check date range in filter
- ✓ Ensure correct shop is selected
- ✓ Check your internet connection

### Incorrect Entry
- ✓ Click trash icon to delete
- ✓ Re-enter with correct information
- ✓ Note the correction in PDF forms for reference
