INVOICE LOOKUP PROCESS:

Input: Tenant ID (national ID)
  ↓
Validate: Check ID format
  ↓
Search Tenants: Loop through all users
  - For each user: Query tenants collection
  - Match: where('localId', 'in', [tenantId, tenantIdNum])
  ↓
Find Invoice: For matched tenant
  - Get assetId (landlord/owner)
  - Query: users/{assetId}/invoices
  - Match: where('tenantId', 'in', searchIds).where('isPaid', '==', false)
  ↓
Retrieve Data:
  - Invoice document data
  - Including: pdfUrl (if exists)
  ↓
Display Invoice:
  - Tenant name
  - Rent breakdown (rent, water, power, other)
  - Total amount
  - Amount paid
  - Outstanding balance
  - Billing month
  - Due date (if exists)
  - Paid date (if exists)
  ↓
PDF Section:
  - If pdfUrl exists: "📥 *Download Invoice:*\n{pdfUrl}"
  - If no pdfUrl: "⚠️ *PDF not yet generated*"
  ↓
Navigation:
  - 0 = Back to MAIN_MENU
  - 00 = Restart (ask for ID)
  - 000 = Exit to language selection
