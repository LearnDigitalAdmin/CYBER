🚀 QUICK START
═══════════════════════════════════════════════════════════════════════════════

  1. Setup Environment
     cd functions
     cp .env.example .env
     # Edit .env with WhatsApp & Paystack credentials

  2. Build
     npm run build          # Compiles TypeScript to JavaScript

  3. Deploy
     firebase deploy --only functions

  4. Configure WhatsApp
     → Go to Meta App Dashboard
     → Set Webhook URL to your Cloud Function
     → Verify token matches WHATSAPP_VERIFY_TOKEN
     → Subscribe to 'messages' field

  5. Test
     → Send message to your WhatsApp number
     → Should see language selection menu
     → Reply 1 for English
